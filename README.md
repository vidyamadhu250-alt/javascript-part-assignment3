# Part Assignment 3 – JavaScript Programming

## Project Description
This project contains JavaScript programs covering functions, arrow functions, control flow, arrays, array methods and asynchronous JavaScript.

## Task 1: Functions and Control Flow
This program calculates and displays the results of four learners using functions and a for...of loop.

## Task 2: Arrays and Array Methods
This program uses forEach(), map() and filter() to display student details, student names and students who scored 80 or above.

## Task 3: Asynchronous JavaScript
This section explains callbacks, Promises, Promise states and Async/Await.

## Execution Steps
1. Install Node.js.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run Task 1 using: `node function.js`
5. Run Task 2 using: `node Array.js`
6. Check the output in the terminal.
